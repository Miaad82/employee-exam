# منصة اختبارات الموظفين — دليل التشغيل

## التشغيل محلياً
    npm install
    ADMIN_PASSWORD="123456" SECRET="نص-عشوائي-طويل" npm start
ثم افتح http://localhost:3000

## النشر على الإنترنت (مثال: Render أو Railway)
1. ارفع هذا المجلد إلى مستودع GitHub.
2. أنشئ خدمة Web Service جديدة واربطها بالمستودع.
   - أمر البناء: `npm install`
   - أمر التشغيل: `npm start`
3. أضف متغيرات البيئة:
   - `ADMIN` كلمة مرور المسؤول (إلزامية)
   - `SECRET` نص عشوائي طويل لتوقيع الجلسات
   - `DB_PATH` مسار قاعدة البيانات على قرص دائم، مثل `/data/data.db`
4. اربط قرصاً دائماً (Persistent Disk / Volume) على المسار `/data`. بدونه تُمسح البيانات عند كل إعادة تشغيل.
5. أرسل رابط الخدمة للموظفين.

## ملاحظات
- كلمات مرور الموظفين مُشفّرة ولا يمكن عرضها. استخدم "كلمة مرور جديدة" لإعادة تعيينها.
- الإجابات الصحيحة لا تصل إلى متصفح الموظف، والتصحيح يتم على الخادم.
- يُنصح بالنشر خلف HTTPS (توفره المنصات تلقائياً).
